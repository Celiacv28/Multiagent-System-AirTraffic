Simulación de Aeropuertos y Aviones con Agentes Multi-Agente (AutoGen Core)

Este proyecto implementa una simulación de aviones y aeropuertos utilizando el framework autogen-core, donde cada aeropuerto y avión es un agente autónomo que se comunica mediante mensajes directos.
El sistema incluye una lógica de asignación de pistas con aprendizaje por refuerzo (Q-learning) para reducir retrasos y optimizar operaciones.
